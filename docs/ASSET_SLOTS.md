# Asset slots

Every asset below is a **generated placeholder**. Replacing one is a drop-in
file swap: keep the file name, re-import, done. Nothing references final art
yet, so no code changes are needed.

All audio is 44.1 kHz, mono, 16-bit PCM, peak-normalized to 0.9 (-1 dBFS-ish).
The music loop is normalized to 0.55 so it sits under the SFX.

Mass events go through `AudioManager.play_sfx_throttled(id, seconds)` so the
12-voice SFX pool never machine-guns when a whole wave dies at once.

Regenerate them all:

```powershell
godot --headless --path . --script res://tools/gen_placeholder_sfx.gd
```

The generator is deterministic (fixed RNG seed), so re-running produces
byte-identical files on the same engine version.

**Replacing a sound:** overwrite the `.wav`, or drop in a `.wav`/`.ogg` with the
same basename. `AudioManager` scans the folder at startup and keys sounds by
file basename, so `hit.ogg` replaces `hit.wav` only if you delete the `.wav`
(otherwise whichever loads last wins). Keep SFX under ~0.6 s and pre-trimed
silence at the head.

## 2. Audio — music

Directory: `assets/audio/music/`
Bus: **Music**, crossfade 0.4 s, ducks -6 dB while paused.

Music is **scene-owned**: `MainMenu._ready()` calls
`AudioManager.play_menu_music()` and `Battle._ready()` calls
`AudioManager.play_battle_music()`, so each scene brings its own track.
`Battle.end_run()` fades the battle theme out under the results transition, so
the results screen is SFX-only. Nothing starts music at boot.

| Slot | File | Length | Status |
|---|---|---|---|
| `menu_theme` | `menu_theme.mp3` (or `.ogg` / `.wav`) | any | Menu soundtrack. Missing file → falls back to `grove_loop`. |
| `battle_theme` | `battle_theme.mp3` (or `.ogg` / `.wav`) | any | Battle soundtrack. Missing file → a run stays silent (SFX only). |
| `grove_loop` | `grove_loop.wav` | 30.00 s | Generated placeholder loop, menu fallback only |

**Adding a track:** drop the file into `assets/audio/music/`, name it
`menu_theme.<ext>` or `battle_theme.<ext>`, and reopen the project — the folder is
scanned once at startup. Looping is forced in code for WAV, Ogg and MP3, so no
import-dock setup is required. If two files share a basename (`battle_theme.wav`
and `battle_theme.mp3`), the more compressed one wins (ogg > mp3 > wav). Keep the
themes around 0.5 peak so the SFX sit on top of them.

**This is the one intentional deviation from the stage spec**: the slot is
documented as `grove_loop.ogg`, but GDScript has no Vorbis encoder and this
machine has no `ffmpeg`/`oggenc`, so the loop ships as a WAV. The WAV is 2.5 MB
mono; the whole APK is 56.2 MB, well under the 80 MB budget.

To move to Ogg Vorbis (recommended before release — it is ~10x smaller):

1. Encode the real track: `ffmpeg -i grove_loop.wav -c:a libvorbis -q:a 5 grove_loop.ogg`
2. Delete `assets/audio/music/grove_loop.wav` (and its `.import`).
3. Drop `grove_loop.ogg` in the same folder. `AudioManager` already scans for
   `.ogg` and forces `LOOP_FORWARD` when it opens the stream.
4. In the import dock set **Loop → Forward** and **Compress → Vorbis** so the
   loop is gapless on device.

The loop point is the file boundary; both ends are tapered by 4 ms so the seam
never clicks.

### Battle art

Every file is optional and loaded by path through `ArtLibrary`
(`scripts/core/art_library.gd`). Delete a file and that object draws itself
procedurally again; add it and no code or scene change is needed. Sizes are at
the 1080×1920 design scale — export at 1.5–2× and power-of-two.

| Slot | File | Suggested | Notes |
|---|---|---|---|
| Arena ground | `battle/arena_ground.png` | 1024² | mapped into the 500 px playfield circle |
| Tree | `tree/tree_body.png` | 512² | pivot at the trunk base; `art_offset` on Core (default `(0,-96)`) |
| Orcs | `enemies/orc_grunt.png`, `orc_runner.png`, `orc_brute.png`, `orc_warlord.png` | 128²–384² | drawn 2.8× the body radius, centred on the body |
| Towers | `towers/<id>_l<level>.png` (e.g. `archer_tower_l2.png`) or `towers/<id>.png` | 192×256 | drawn 4.2× body radius tall, pivot at the pad centre |
| Archer | `archers/archer.png` | 128² | faces +x, drawn 46 px |
| Build pad | `battle/build_pad.png` | 128² | drawn 2.3× `BODY_RADIUS` |
| Projectiles | `projectiles/arrow.png`, `frost_bolt.png`, `ballista_bolt.png` | 64² | rotates with the node |

### UI art

`UISkin` (`scripts/ui/ui_skin.gd`) applies these to `ui/theme.tres` once at boot.
Every file is optional; a missing one keeps the current flat style.

| Slot | File | Notes |
|---|---|---|
| Buttons | `ui/button_normal.png`, `_hover`, `_pressed`, `_disabled` | 9-patch, 36 px corners |
| Primary CTA | `ui/button_primary_<state>.png` | overrides `PrimaryButton` |
| Danger | `ui/button_danger_<state>.png` | overrides `DangerButton` |
| Tabs | `ui/tab_<state>.png` | overrides `TabButton` |
| Panels | `ui/panel.png` | 9-patch for `PanelCard` |
| HP bars | `ui/hp_bar_bg.png`, `ui/hp_bar_fill.png` | stretched, not 9-patch |
| Menu background | `ui/menu_background.png` | full-screen, behind every tab |

9-patch panels: keep the corner detail inside the outer 36 px and let the middle
stretch; import with mipmaps off and lossless compression.

Recommended import settings once the artwork is final: **VRAM Compressed**
(ETC2/ASTC on Android) with **mipmaps on**, filter linear. The current
placeholder imports as lossless, which is fine while it is a flat colour.

## 4. Fonts

No font file ships. `ui/theme.tres` uses a `SystemFont` with fallbacks
`Roboto, Noto Sans, Segoe UI, DejaVu Sans`, which covers Ukrainian
(`Ї ї Є є Ґ ґ І і`, `—`) on both Android and Windows —
`tests/TestGlyphs.tscn` verifies every character used in `strings.csv`.

If a target device lacks a fallback, bundle a font:

1. Add `assets/fonts/NotoSans.ttf`.
2. In `ui/theme.tres`, replace the `SystemFont` sub-resource with a
   `FontFile` ext-resource.
3. Re-run `TestGlyphs` — it reads whatever the theme resolves.

## 5. Texture compression

`project.godot` has `textures/vram_compression/import_etc2_astc = true`, so the
Android export uses ETC2/ASTC. Current art is all vector or tiny generated PNGs;
no texture is larger than 1080×1920.

When final art arrives: keep textures power-of-two where practical, enable
**VRAM Compressed** in the import dock, and never ship an uncompressed 4K
sheet (master §8.3).
